提交 → 结果的编排

现状：提交仅禁用按钮，结果硬切入。改为按钮 loading 态给进行中反馈，结果从 scale(0.98)+opacity:0 落定——元素不该凭空出现。点两侧"提交"对比。

05

放行/拦截 verdict 的克制强调

verdict 是整页高潮，值得一次落定强调；但因高频查看不宜过度——所以只在首现时 scale 落定，重复渲染不再动。语义色（allow 绿 / deny 红）独立于品牌青，凭形与色双通道读出。

约束已保留：页面已在 @media (prefers-reduced-motion: reduce) 下降级—— 本原型同样在该模式下只保留 opacity、去掉所有位移与缩放。所有动效时长 <300ms，仅动 transform 与 opacity（走 GPU）。落地时改动集中在 app.css、 RequestLimitMeter.tsx 与几个按钮，不触碰任何安全语义或无障碍活区。
