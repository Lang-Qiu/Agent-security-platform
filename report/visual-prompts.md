## 1. Untrusted Content to Real Action

Target file: `report/figures/page_2.png`

Recommended aspect ratio: 16:7, landscape, minimum 2400 x 1050 px.

Prompt:

```text
Create a clean, high-information cybersecurity editorial illustration for a
Chinese technical competition report. Show a left-to-right five-stage causal
chain: untrusted external content entering from a web page, retrieved document,
and persistent memory; an AI agent planning node; structured tool parameters;
three concrete possible consequences (an outgoing email containing protected
data, an unauthorized protected-file read, and a poisoned memory write); then a
runtime security barrier intercepting the action immediately before execution.
Make the runtime barrier the visual focal point and show the harmful route
stopping there. Use a light gray-white canvas, restrained cyan/teal for normal
system flow, green for allowed flow, orange for escalation, red for blocked
harm, and deep navy for evidence. Use crisp 2D information-design composition,
subtle depth, precise connectors, and professional Chinese cybersecurity report
styling. No decorative gradients, no 3D chart, no stock-photo look, no brand
logos, no university identity, no people, no readable personal data, and no
large embedded text. Leave clean visual zones so LaTeX captions can explain the
stages. Do not imply that a model alone prevents the attack; the interception
must visibly occur at the runtime tool boundary.
```

Factual boundary: this image is explanatory, not experimental evidence. It may
illustrate the consequence classes but must not display benchmark values or
claim a measured detection result.
