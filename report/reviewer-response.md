# 审稿意见回应

## 意见一：摘要进一步简化

**审稿意见概述**

摘要应直接说明智能体面临的风险与作品作用，减少攻击回放、测评指标和证据编号对首次阅读的干扰。

**回应与修改**

接受该意见。摘要继续保留“现实问题—系统作用—核心机制—交付证据”的主线，并完成两项删减：

1. 删除“不可信检索内容劫持 `send_email`”受控攻击回放段落。
2. 删除五项测评指标以及 P6/P7 说明，不在摘要中展开 88.33%、93.33%、1.67%、90.74%、99.33% 等数据。

修订后的摘要先说明智能体能够调用工具并产生数据外送、越权访问和危险写入等现实后果，再说明本作品如何以三级级联、四值动作、确定性脱敏和 OpenClaw 四个真实执行点控制这些行为。300 条评测夹具仍作为交付规模证据保留，具体指标与证据含义放在第三章展开。

**修改位置**

- `report/chapters/abstract.tex`

## 意见二：为非智能体方向的信息安全评委解释相关名词

**审稿意见概述**

作品背景中出现了智能体、提示注入、检索投毒、真实执行点、语义沙箱等术语。密码学等其他信息安全方向的评委可能熟悉安全原则，但不熟悉智能体运行机制，需要在进入系统设计前建立共同语境。

**回应与修改**

接受该意见。参考《基于电子指纹的追踪定位系统项目报告》“先解释相关概念，再介绍作品设计”的组织方式，在第一章新增“相关概念”，用攻击后果和系统职责解释七组术语：

1. 大模型智能体。
2. 提示注入、检索投毒与记忆投毒。
3. 工具调用与真实执行点。
4. 运行时安全中间件与语义沙箱。
5. 三级级联与四值动作。
6. 确定性脱敏与令牌化。
7. 内容无关审计与 P6/P7 证据。

这些解释服务于作品理解，不扩展系统能力主张。读者可先理解“外部内容如何变成真实动作、错误动作会造成什么后果、系统在哪个位置阻断”，再阅读三级级联和 OpenClaw 适配细节。

**修改位置**

- `report/chapters/ch1-overview.tex`
- 第一章“相关概念”小节
